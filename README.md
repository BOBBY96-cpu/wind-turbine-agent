# Wind Turbine O&M Intelligent Agent

AI-powered fault diagnosis and decision-making system for wind turbine operation and maintenance.

---

## 🚀 Project Overview

This project is an intelligent Agent system designed for wind turbine fault diagnosis in real-world O&M scenarios.

It simulates how experienced field engineers analyze faults by combining:

- SCADA data analysis
- PLC signal logic
- Electrical schematic reasoning
- Historical case retrieval
- Step-by-step troubleshooting paths

---

## ⚡ Core Features

- 🔍 Automatic fault parsing (alarm → structured data)
- 🧠 Multi-Agent reasoning (data / logic / knowledge / decision)
- 📊 SCADA + PLC signal correlation
- 📚 Knowledge base reuse (historical cases)
- 🛠 Step-by-step troubleshooting guidance
- ⚠️ Risk-aware decision suggestions

---

## 🧩 System Architecture
Input (Alarm / SCADA / Logs)
