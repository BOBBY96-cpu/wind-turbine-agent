# Fault Case Examples

## 1. Yaw Feedback Loss

### Symptom
Right yaw feedback lost during yaw start.

### Diagnosis Path
- Check yaw command
- Check contactor
- Check relay feedback
- Check 24V circuit
- Check PLC DI signal

---

## 2. Communication Failure

### Symptom
Multiple turbines lose communication sequentially.

### Diagnosis
- Check fiber ring topology
- Check switch ports
- Check optical module
